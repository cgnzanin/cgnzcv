Sobre Mim

Sou um economista formado pela USP que mergulhou fundo no desenvolvimento de software. Com mais de 5 anos de experiência em gestoras de fundos, transformei a maneira como o backoffice e a análise de dados funcionam.

Minha especialidade é construir infraestruturas robustas e de baixo custo, utilizando tecnologias como Supabase, Python e Github Actions. Não apenas escrevo código, mas entendo a lógica financeira por trás de cada linha, o que me permite criar soluções como o Rating Flow e sistemas complexos de precificação (Curvas DI1).

Atualmente, sou entusiasta de IA, utilizando ferramentas como Antigravity e Claude Code para acelerar o desenvolvimento e NotebookLM para manter-me atualizado em geopolítica e tecnologia.
